# Diplom_1: юнит-тесты Burger

Java 11, Maven, JUnit 4.13.2, Mockito 3.12.4, JaCoCo 0.8.10.

## Запуск

Выберите JDK 11 в настройках проекта и Maven Runner в IntelliJ IDEA.

```sh
mvn clean verify
```

Отчёт: `target/site/jacoco/index.html`.

Проверяются выбор булочки, добавление и удаление ингредиентов, перемещение
в обе стороны и на текущую позицию, цена и полный текст чека с ингредиентами
и без них. Параметризация использована для цен и перемещений; булочки и
ингредиенты подменены моками Mockito. Ожидаемые суммы заданы явно.

Цель покрытия по заданию - класс `praktikum.Burger`. JaCoCo проверяет для него
100% строк, инструкций и ветвей. Исходный код приложения не менялся.

Проверка 29.10.2026: 16 тестов, 0 ошибок, 0 пропусков. `mvn clean verify`
завершился успешно. Отчёт JaCoCo показал 100% покрытия класса Burger.

Сохранённый отчёт этого прогона приложен в папке [jacoco](jacoco/).
Откройте `jacoco/index.html` в браузере. В папку также включены
машиночитаемые отчёты `jacoco.xml` и `jacoco.csv`.

Исходный проект: https://github.com/yandex-praktikum/QA-java-diplom-1
